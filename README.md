# UrbanAnimeTv v5

Complete static site package for UrbanAnimeTv.

Included:
- index.html
- style.css
- app.js
- config.js (keep your existing real Supabase publishable key)
- supabase-schema.sql
- urbananimetv-logo.png (user-supplied transparent logo)
- hoodgods-thumbnail.png

Current site content:
- HoodGods
- City of Ash
- No Street Kings

Account features:
- Supabase sign up / sign in / sign out
- My List
- Watch History
- Continue Watching hidden until watch progress/history exists

Logo:
- Uses the supplied UrbanAnimeTv transparent PNG.
- Header size is balanced for desktop and mobile.
- Footer uses a slightly larger version for visibility.

Important:
- Do not replace config.js if your GitHub version already contains your real Supabase publishable key.
- Full-length video files should be hosted separately from GitHub/Cloudflare Pages.


Current episode catalog: HoodGods — Season 1, Episode 1: “The Beginning” only. No additional episodes are listed yet.
