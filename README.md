# UrbanAnimeTv v1

Free static streaming-app prototype.

## Put your first video online
Create/use the `videos` folder and add:
`videos/hoodgods-episode-1.mp4`

Then the Watch buttons will open the built-in video player.

## What v1 includes
- UrbanAnimeTv branding
- Home page
- Featured series
- Movies section
- New Releases section
- Search
- Full-screen video player
- Mobile-friendly layout

## What v1 does not include yet
Accounts, subscriptions, payments, database, synced watch history, admin uploads, or protected video delivery.

## Free hosting
Cloudflare Pages supports static HTML sites. Connect this folder to a Git repository and deploy it with a build command of `exit 0`; the folder containing `index.html` is the output directory.
